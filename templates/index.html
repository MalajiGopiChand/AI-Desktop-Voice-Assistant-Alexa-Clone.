Voice & Remote Desktop Command Cheat-Sheet

Full list of supported voice commands, chat reading, email answering, popup handling, and mouse control protocols.

Voice Mouse & Screen Remote Controls

Control your desktop cursor and screen directly using your voice or Web UI.

  • scroll mouse down / scroll down — Scroll active window downwards
  • scroll mouse up / scroll up — Scroll active window upwards
  • move mouse right 150 / move mouse left — Move cursor relative position
  • right click — Execute mouse right click at pointer
  • left click — Execute mouse left click at pointer
  • double click — Execute double click
  • press enter / press space / press tab — Key presses

Chat Reading & Email Answering

Metis can read visible chat screen content, draft replies, and explain alert popups.

  • read chats / read whatsapp — OCR vision reads active chat & summarizes messages
  • send message <text> — Paste text and press Enter in open chat
  • open whatsapp and send message to <contact>: <text> — Auto open chat & message
  • answer email / reply email — Reads open email text & drafts reply
  • explain popup — OCR vision reads active popup alert & explains required action

Application Launcher Shortcuts

Instant launch aliases for desktop software and web apps.

  • open copilot / ko pilot — Launch Microsoft Copilot
  • open whatsapp / whats app — Launch WhatsApp Desktop
  • open chrome — Launch Google Chrome
  • open notepad — Launch Windows Notepad
  • open vscode / vs code — Launch Visual Studio Code
  • open excel / word / powerpoint — Launch MS Office

Media & Video Playback Controls

Control YouTube and browser video streams with voice.

  • play pause video / pause — Toggle video play/pause
  • seek forward / seek backward — Skip 10 seconds forward/backward
  • fullscreen video — Toggle full-screen mode
  • search youtube for <query> — Open & play YouTube video
